# NexaWork – Presentation & Live Demo Guide

This guide provides a slide-by-slide script, key feature callouts, and step-by-step demonstration walkthrough for presenting **NexaWork**.

## 🎬 Live Demo Script (Step-by-Step)

### Step 1: Landing Page & NexaAI Assistant Widget
- **Action**: Open `http://localhost/PHP/freelancehub`
- **Highlight**:
  - Point out the **Live Activity Ticker** at the top showing real-time bids and hires.
  - Demonstrate the **Hero Search Autocomplete** by typing `React` or `Web`.
  - Click the **Floating NexaAI Widget** on the bottom right and click "Top Freelancers" or type "Find Python developers under ₹40,000".

### Step 2: Posting a Project with AI Scope Generator
- **Action**: Log in as a Client (`rajesh.kumar@email.com` / `password`), click **Post New Project**.
- **Highlight**:
  - Enter Title: `Build a Full-Stack React E-Commerce Store`
  - Select Category: `Web Development`
  - Click **Auto-Generate Scope**.
  - Show how NexaAI automatically generates a structured project description with deliverables, milestones, and suggested budget.

### Step 3: Freelancer Bidding & AI Proposal Optimizer
- **Action**: Log in as Freelancer (`arjun.singh@email.com` / `password`), navigate to **Browse Projects**, select the project, click **Submit Bid**.
- **Highlight**:
  - Type a cover letter.
  - Click **NexaAI Review Proposal**.
  - Show the proposal quality score, tips for improvement, and budget alignment feedback.

### Step 4: Admin Dashboard, User Management & Analytics
- **Action**: Log in as Admin (`admin@freelancehub.com` / `password`).
- **Highlight**:
  - Navigate to **User Management** (`admin/users.php`): Filter users by role and status, toggle the **Verified Badge** for a freelancer.
  - Navigate to **Analytics** (`admin/analytics.php`): Show monthly revenue curve, category distribution chart, top earners table, and click **Export Financial Report** to download the CSV.

### Step 5: Freelancer Portfolio Showcase & Trust Score
- **Action**: Open public profile `freelancer-profile.php?id=4` (Arjun Singh).
- **Highlight**:
  - Show the **Trust Score Badge** gauge and verified status.
  - Showcase the portfolio grid with image previews and live demo links.

## 📊 Key Highlights for Evaluators

1. **AI-Powered Core**: Real-time project scope generation, proposal optimization, semantic matching, and assistant bot.
2. **Escrow & Financial Safety**: Phased contract milestone payments, locked escrow tracking, and transparent dispute handling.
3. **Enterprise Security**: BCrypt password hashing, CSRF verification, finfo MIME file upload validation, and `.htaccess` execution blocking.
4. **Modern UI/UX**: Dark mode support, glassmorphism UI elements, Chart.js visualizations, and animated counter statistics.
